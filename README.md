## Contact form email

The contact form uses FormSubmit and sends messages to `ememeemmanuel3@gmail.com`. No custom domain or API key is needed. After deploying, submit one test message and confirm FormSubmit's activation email in that inbox (check Spam if it is not visible). Form submissions will be delivered after confirmation. The email link on the Contact page remains available as a direct alternative.
